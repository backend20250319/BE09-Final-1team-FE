# 🔗 백엔드 API 연결 설정

이 문서는 NewSphere 프론트엔드와 백엔드 API 연결 설정을 설명합니다.

## 📋 환경 변수 설정

### 1. .env.local 파일 생성

프로젝트 루트 디렉토리(`news2/`)에 `.env.local` 파일을 생성하세요:

```bash
# 백엔드 API 기본 URL
NEXT_PUBLIC_API_BASE_URL=http://localhost:8080

# 기타 설정
NEXT_PUBLIC_APP_NAME=NewSphere
NODE_ENV=development
```

### 2. 백엔드 서버 확인

백엔드 서버가 다음 엔드포인트들을 제공하는지 확인하세요:

- `GET /api/news/search` - 뉴스 검색
- `GET /api/news/trending-keywords` - 트렌딩 키워드
- `POST /api/subscribe/keywords` - 키워드 구독 추가
- `GET /api/subscribe/keywords` - 키워드 구독 조회
- `DELETE /api/subscribe/keywords` - 키워드 구독 취소

## 🚀 사용 방법

### 1. 개발 서버 시작

```bash
# 프론트엔드 개발 서버 시작
cd news2
npm run dev
# 또는
yarn dev
# 또는
pnpm dev
```

### 2. 백엔드 서버 확인

백엔드 서버가 `http://localhost:8080`에서 실행 중인지 확인하세요.

### 3. 기능 테스트

- **검색**: 헤더의 검색창에서 타이핑
- **키워드 클릭**: 실시간 키워드 위젯의 키워드 클릭
- **연관 기사**: 뉴스 상세 페이지의 관련 키워드 칩 클릭

## 🔧 문제 해결

### 1. CORS 오류

백엔드에서 CORS 설정이 필요할 수 있습니다:

```java
@CrossOrigin(origins = "http://localhost:3000")
```

### 2. API 연결 실패

- 백엔드 서버가 실행 중인지 확인
- 포트 번호가 올바른지 확인
- 환경 변수가 올바르게 설정되었는지 확인

### 3. 환경 변수 로드 확인

브라우저 개발자 도구에서 다음을 확인:

```javascript
console.log(process.env.NEXT_PUBLIC_API_BASE_URL)
```

## 📝 구현된 기능

### ✅ 완료된 기능들

1. **헤더 통합 검색 + 자동완성**
   - 실시간 검색 제안
   - 키보드 네비게이션
   - 인기 키워드 제안

2. **키워드 검색 결과 페이지**
   - Spring Boot Pageable 구조 지원
   - 탭 기능 (최신순/언론사별/카테고리별)
   - 페이지네이션

3. **실시간 키워드 위젯**
   - 키워드 클릭 시 검색 페이지 이동
   - 트렌딩 키워드 API 연동

4. **뉴스 상세 페이지**
   - 관련 키워드 칩 클릭 시 검색 이동
   - 연관 기사 컴포넌트

5. **키워드 구독 시스템**
   - 키워드 구독/취소
   - 구독 목록 관리

## 🎯 API 엔드포인트

모든 컴포넌트가 다음 백엔드 API를 직접 호출합니다:

- `GET ${API_BASE_URL}/api/news/search?query=키워드&page=0&size=20`
- `GET ${API_BASE_URL}/api/news/trending-keywords?limit=10&period=24h`
- `POST ${API_BASE_URL}/api/subscribe/keywords`
- `GET ${API_BASE_URL}/api/subscribe/keywords?userId=123`
- `DELETE ${API_BASE_URL}/api/subscribe/keywords?id=456`

## 🔄 개발 워크플로우

1. 백엔드 서버 시작 (`http://localhost:8080`)
2. 프론트엔드 개발 서버 시작 (`http://localhost:3000`)
3. `.env.local` 파일에서 API URL 설정
4. 브라우저에서 `http://localhost:3000` 접속
5. 기능 테스트 및 개발 진행
